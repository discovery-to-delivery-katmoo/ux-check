# Build brief: Shiftboard

## 1. Goal
A small task board for a 6-person café kitchen team, so the head chef sees what's blocked before service.

## 2. People and what they need
- **Head chef (lead):** needs to see what's blocked or overdue before service, in seconds, and reassign it.
- **Kitchen staff:** need to see their own tasks for today and mark them done with one tap.

## 3. Main tasks
1. Head chef sees blocked tasks and reassigns one to someone else.
2. Staff member sees their tasks for today.
3. Staff member marks a task done.
4. Head chef adds a task for today.
